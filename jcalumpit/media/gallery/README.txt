Put your clinic photos (.jpg, .jpeg, .png, .webp) in this folder.
They appear on the landing page and gallery.html automatically - no upload needed.
Name them 01.jpg, 02.jpg ... to control the order. A file name like 'reception-area.jpg' becomes the caption 'Reception area'.
Small thumbnails are created on first view in the 'thumbs' subfolder (needs the GD extension).
